C:\Users\You> focusd --features

[PRIVACY]

Zero data exfiltration. All data stored locally in %APPDATA%\focusd\. No cloud, no accounts.

[TUI DASHBOARD]

Full-screen terminal UI with dashboard, stats, focus timer, limits, and settings tabs.

[BROWSER TRACKING]

Tracks time per browser tab by page title. Smart grouping for 80+ sites (YouTube, GitHub, etc).

[POMODORO TIMER]

Built-in focus sessions with system notifications. Configurable duration and break reminders.

[APP LIMITS]

Set daily time limits for distracting apps. Get notified when limits are exceeded.

[PERFORMANCE]

Written in Go. ~0% CPU, ~5MB RAM. Single ~11MB binary. No dependencies.

[BREAK REMINDERS]

Configurable reminders after N minutes of continuous use. Snooze or disable per session.

[DATA CONTROL]

Configurable retention (1-30 days). Export to CSV. Wipe data anytime. Open SQLite database.

[AUTO-START]

Optional Windows startup integration. Runs silently in background as a daemon process.
